# Android-клиент

Текущий Windows runtime нельзя безопасно перенести в APK целиком: он использует Python/Telethon, локальный Codex CLI и фоновые desktop-процессы.

Рекомендуемая схема:

- сервер хранит Telethon-сессии, синхронизирует Telegram и запускает AI;
- Android-приложение показывает аккаунты, чаты, AI-варианты и настройки автопилота;
- обмен идёт через HTTPS API и WebSocket для новых сообщений;
- вход в Telegram выполняется через QR или код, а session-файл остаётся только на сервере;
- доступ к мобильному API защищается отдельной авторизацией пользователя и шифрованием секретов на сервере.

Фронтенд React можно переиспользовать через Tauri 2 Mobile или Capacitor. До мобильной сборки серверный API нужно отделить от `127.0.0.1`, добавить пользователей, токены доступа, WebSocket и безопасное хранилище Telegram-сессий.

Первый мобильный релиз разумно ограничить просмотром чатов, уведомлениями, AI-вариантами и ручной отправкой. Управление автопилотом добавляется после проверки серверной изоляции аккаунтов.
