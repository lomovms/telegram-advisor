# Передача Telegram Advisor другому пользователю

Передавайте только MSI:

`web-ui/src-tauri/target/release/bundle/msi/Telegram Advisor_0.1.0_x64_en-US.msi`

В установщик не входят `.env`, базы SQLite и Telegram session-файлы.

При первом запуске пользователь:

1. Создаёт Telegram API ID и API Hash на `my.telegram.org`.
2. Вводит их для рабочего аккаунта и сканирует QR в Telegram.
3. При необходимости подключает личный аккаунт. Он использует те же API ID/Hash, но отдельную Telegram-сессию.
4. Нажимает вход в Codex и авторизуется своей учётной записью ChatGPT.

Пользовательские данные создаются в локальной папке приложения внутри `%LOCALAPPDATA%`.
Удаление или передача файлов `*.session` может привести к потере сессии или доступу к Telegram-аккаунту третьими лицами.

MSI пока не подписан сертификатом издателя, поэтому Windows SmartScreen может показать предупреждение о неизвестном издателе.
